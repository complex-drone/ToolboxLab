### 2.3 构建与部署验证
- `npm run build` 48.6s 成功，无 crypto/stream 外部化警告。
- 预渲染 **283 页**（zh 141 + en 141 + 404.html）✓；282 个 locale HTML + 404 + 根 index。
- sitemap：sitemapindex + 双语言子表（141 URL × 2，含 lastmod/xhtml:link）。
- 静态页 SEO：双语言独立 `<title>`/`<meta description>`、canonical 自指、hreflang zh/en/x-default、OG 齐全；正文内容已静态可见（爬虫无需 JS）。
- **生产 404（线上实测）**：`https://toolboxlab.pages.dev/en-US/not-exist` → HTTP 404 + 404 页（无软 404）。
- 生产懒加载：首页 4 请求/254KB；mermaid 页按需加载 3 个 mermaid 分块（159KB gzip）并正常渲染。
- `dist/_headers` CSP/HSTS/XFO 齐全；`_redirects` 短链/旧路径 301 正确。

## 3. 失败/问题清单

| 编号 | 用例 | 现象 | 严重度 | 修复建议 |
|------|------|------|--------|----------|
| BUG-1 | SPA 同语言导航元数据 | 客户端点击导航（首页→工具、相关工具互跳）后 URL 变化但 `document.title` 与 `canonical` 停留上一工具（如 en-US/json-formatter→timestamp-converter 后 title 仍为 "JSON Formatter and Validator"）；仅切换语言时才刷新 | **P1** | SEO 元数据更新应同时监听 `route.path/fullPath`（当前疑似仅监听 locale）；在路由后置守卫统一刷新 title/description/canonical/OG |
| BUG-2 | `/password` 页面缺 H1 | 密码生成器（139 工具中唯一复用共享组件的页面）标题使用 H2，页面无 `main h1`，双语言一致 | **P2** | 将 PasswordGenerator 卡片标题改为 `h1`（或在 ToolPage 外壳内补 h1），对齐其余 138 个工具页 |
| BUG-3 | 移动端触控目标 | 移动端（375×812）缩进 chip、格式化/压缩结果切换 chip 高度约 22px，主按钮 34~39px，均低于 44px 触控标准 | **P2** | chip 类控件增加 `min-h-[36px]~44px` 与更大点击热区（伪元素扩展），或移动端改为分段控件 |
| OBS-4 | K8s Service 默认无 selector | 默认表单生成的 Service YAML 无 `spec.selector`（直接 apply 不会关联 Pod）；手动添加标签后正确生成 `selector: app: my-app` | P2（改进） | Service 页签默认带 `app: <资源名>` selector 行，或给出提示 |
| OBS-5 | dev/preview 软 404 | 本地 dev/preview 下未知路径被 SPA 重定向至 `/zh-CN/`（返回 200）；生产 Cloudflare Pages 已验证返回 404+404 页 | P3 | 属预览环境差异，无需改代码；如需本地一致可在 vite preview 配置 404 回退 |
| OBS-6 | Toast 位置 | 测试计划期望移动端弹窗/Toast 居中，实际为右上角（功能正常） | P3 | 设计确认；如需居中仅改 Toast 定位类 |
| OBS-7 | 文档偏差 | README/徽章写 148 个测试用例，实际 152 个（全通过）；首页 title 为 "ToolboxLab"（静态页正常） | P3 | 更新 README 数字；SPA 首页 title 可加品牌后缀 |

## 5. 修复建议

**P0（阻塞上线）**：无。

**P1（建议本周）**
1. BUG-1：路由级 SEO 元数据刷新（title/canonical/description/OG 与 `route` 绑定）。对纯静态托管影响有限（直链均为预渲染 HTML），但影响 SPA 体验与 JS 渲染爬虫的站内跳转抓取。

**P2（近期迭代）**
2. BUG-2：`/password` 补 H1。
3. BUG-3：移动端触控目标 ≥44px。
4. OBS-4：Service 默认 selector。

**P3（随手优化）**
5. README 测试数 148→152；Toast 移动端位置确认；SPA 首页 title 增加"— 纯前端本地工具集"等描述；可补 skip-link；浏览器语言回退与多 Toast 堆叠补测。

## 6. 测试结论

**可以发布上线**。139 个工具 × 2 语言共 278 个路由全部可访问且无错误边界触发；20 个 P0 工具深度用例全部通过；XSS/非法输入防护有效；构建、预渲染、sitemap、SEO、生产 404、懒加载与安全头全部符合预期。

遗留风险：① BUG-1（SPA 站内导航元数据不刷新）对 SEO 影响被预渲染架构大部分对冲，仍建议本周修复；② 文件上传类工具（PDF/图片/Excel/EXIF/校验和等 15+ 项）的上传交互与 Edge/Firefox/Safari 真机兼容性因运行时限制未覆盖，建议在常规浏览器中人工补测或引入支持文件上传的 Playwright 流水线；③ 生肖按公历年近似为产品既有口径（UI 已注明），如需农历精确需引入农历库。
